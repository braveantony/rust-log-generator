# rust-log-generator 開發成本

這份文件記錄用 Claude Code 開發 [rust-log-generator](../README.md) 用掉多少 token（模型計算文字量的單位）和時間。對話的內容見 [user-questions.md](user-questions.md)。

- 以 API 定價換算，約 **107 美元**，估計範圍是 106 到 108 美元。
- 實際上沒有按用量付費，因為開發用的是 Claude 的訂閱方案。
- 統計期間是 2026-11-05 15:17 到 2026-11-06 13:46（UTC+8）。這段期間包含 user-questions.md 收錄的全部對話（到 11:43 為止），以及之後把專案同步到 GitHub 的工作。製作這份文件本身的用量不在內。

## 花在哪裡

Claude Code 每次向模型送出請求，都會附上到目前為止的整段對話。已經送過的部分從快取（模型那一端暫存的對話內容）讀取，單價是一般輸入的四十分之一。新增的部分要先寫入快取，下一次請求才讀得到。所以用量主要分成三項：

| 項目 | token 數 | 金額（美元） | 占比 |
|---|---:|---:|---:|
| 輸出（模型的回覆和思考過程） | 74 萬 | 36.25 | 36% |
| 寫入快取 | 193 萬 | 34.41 | 34% |
| 讀取快取 | 1 億 2,338 萬 | 30.80 | 30% |
| 沒有經過快取的輸入 | 992 | 0.01 | 不到 1% |
| 合計 | | 101.48 | |

這張表只涵蓋對話紀錄裡查得到的請求，所以合計比 107 美元少，原因見[數字怎麼來的](#數字怎麼來的)。各列的金額經過四捨五入，加起來和合計差 0.01。

**主對話和 subagent。** 主對話占 87.53 美元。主對話另外分派了 12 個 subagent（各自獨立執行一項工作的模型），合計 13.95 美元：

| 模型 | subagent 數 | 金額（美元） |
|---|---:|---:|
| Claude Fable 5.1 | 9 | 13.16 |
| Claude Opus 5.5 | 1 | 0.57 |
| Claude Sonnet 5.5 | 2 | 0.22 |

**對話越長，每次請求越貴。** 下表只算主對話：

| 時段 | 請求數 | 平均每次附上的對話 | 金額（美元） | 平均每次（美元） |
|---|---:|---:|---:|---:|
| 11 月 5 日 15:17 到 11 月 6 日 01:02 | 272 | 27 萬 token | 57.47 | 0.21 |
| 11 月 6 日 09:37 到 13:46 | 70 | 61 萬 token | 30.06 | 0.43 |

第二個時段的請求數只有第一個時段的四分之一，金額卻超過一半。有兩個原因：

- **對話沒有縮短。** Claude Code 在 11 月 5 日 18:55 自動壓縮過一次對話（把舊的內容換成摘要），從 27 萬 token 降到 3 萬。之後對話一路累積到 71 萬 token，到 11 月 6 日 13:35 才第二次壓縮。
- **隔夜之後快取過期。** 主對話的快取保留 1 小時。11 月 6 日 09:38 的第一個請求要把 54 萬 token 重新寫入快取，這一次就是 10.73 美元，占總額的一成，是整個過程中最貴的一個請求。

想減少用量的話，可以在一個階段結束時用 `/compact` 壓縮對話，或用 `/clear` 開始新的對話，隔天再繼續之前尤其值得做。

## 花了多少時間

- **從開始到結束**：22.5 小時。其中 11 月 6 日 01:02 到 09:37 這 8.6 小時沒有任何活動，扣掉之後是 13.9 小時。
- **Claude 在工作的時間**：主對話的 73 個回合合計 3.2 小時。一個回合是從使用者送出訊息，到 Claude 回覆完畢為止。其餘的時間大多是在等使用者的下一則訊息。
- **到 11 月 6 日 01:02 為止的細項**：Claude Code 的紀錄顯示，等模型回應共 1.8 小時，執行工具（指令、讀寫檔案等）共 1.0 小時。這兩個數字包含 subagent，之後的時段沒有這項紀錄。

## 數字怎麼來的

金額分成兩段計算：

| 時段 | 金額（美元） | 來源 |
|---|---:|---|
| 11 月 5 日 15:17 到 11 月 6 日 01:02 | 76.24 | Claude Code 存在對話紀錄裡的費用紀錄 |
| 11 月 6 日 09:37 到 13:46 | 30 到 32 | 把對話紀錄裡每個請求的 token 數乘上單價 |
| 合計 | 106 到 108 | |

第二段是估計值。對話紀錄只記錄一部分的請求，壓縮對話這類請求查不到 token 數。第一段用同樣的算法得到 71.42 美元，比費用紀錄少 6%。第二段算出來是 30.06 美元，照同樣的比例補上之後是 32.08 美元，所以寫成 30 到 32。

單價是從那筆費用紀錄反推的：把紀錄裡各類 token 的數量乘上下面的單價，得到的金額和紀錄裡的金額完全相同。這些單價沒有另外對照官方的價目表。

| Claude Fable 5.1 | 每百萬 token（美元） |
|---|---:|
| 輸入 | 10 |
| 輸出 | 50 |
| 讀取快取 | 0.25 |
| 寫入快取，保留 5 分鐘 | 12.5 |
| 寫入快取，保留 1 小時 | 20 |

主對話的快取保留 1 小時，subagent 的保留 5 分鐘。Opus 5.5 和 Sonnet 5.5 的單價用同樣的方法得到，輸入分別是 4 和 2 美元，輸出分別是 20 和 10 美元。

下面這些沒有算進去：

- **Codex 的兩次獨立審閱**：合計約 17 萬 token，用的是 ChatGPT 帳號登入，同樣沒有按用量計費。
- **使用者的時間**：讀回覆、回答問題、審閱和合併 merge request。
- **其他服務和設備**：GitLab、GitHub、Kubernetes 叢集和執行 Claude Code 的主機。
